SUMMARY OF THE ONLY REAL DEVIATIONS
--------------------------------------------------------------------------------
 1. (8a)/(10e) TWO-PHASE SPLIT - MCS energy-neutrality and "home by end" are
    closed overnight (Phase 2) rather than inside one 24h horizon. Deliberate.
 2. (8b) term_tol = 0.1 kWh - a tiny margin on the CEV terminal (exact at
    term_tol = 0, but that goes infeasible under online-estimator drift).

Everything else is enforced exactly as the PDF specifies (all HARD by default;
only missed-work 12c is soft, which is the PDF's own slack). The rest rule (12e)
is enabled with t_limit = 1 h.

CLOSED-LOOP CORRECTNESS (Shrinking-horizon MPC, modular code MCSModel.jl / MPCLoop.jl):
 - The three rolling rules (rest 12e, precedence 12d, pacing 13) are seeded from a
   SHARED per-CEV applied-activity history, so a within-window limit can no longer
   "leak" work-runs across the every-15-min re-solves (the 8-in-a-row artefact).
 - The keep-up reserve (E7) makes the hard CEV terminal (8b) recursively feasible.
 VERIFIED: synthetic + input Shrinking runs finish with ZERO infeasible windows and
 every constraint satisfied on every row of the realised trajectory.
