================================================================================
 SCENARIO 1 (SHRINKING HORIZON) - CONSTRAINT-BY-CONSTRAINT: CODE vs MODEL
================================================================================
Compares what the Julia code enforces against the formal model (math_model.tex /
the source "Optimization.pdf"). The window MILP is built in code/4_MCSModel.jl
(function build_window_model); the closed loop is code/5_MPCLoop.jl (run_mpc);
the entry point is code/7_Shrinking_Horizon_main.jl. The legacy standalone
code/Scenario_1.jl mirrors the same constraints but is NOT used by the main.

Controller: SINGLE-DAY SHRINKING horizon. Each 15-min step re-solves the entire
remaining daytime [k0 .. n_day] (or [k0 .. k0+H-1] if shrinking=false); only the
first interval is applied and the window shrinks as the day advances. The night is
a deterministic overnight recharge (Phase 2).

THE ONLY DELIBERATE DEVIATIONS
--------------------------------------------------------------------------------
 1. (8a)/(10e) TWO-PHASE SPLIT - MCS neutrality + "home by end" are closed
    overnight (deterministic Phase 2) instead of inside one 24h MILP.
 2. (8b) term_tol = 0.1 kWh - a tiny margin on the CEV terminal that absorbs
    online-estimator drift (exact at term_tol = 0, but that risks infeasibility).

NOTE vs the RECEDING sibling: this Shrinking model is single-day and LUMPSUM, so it
does NOT add the receding version's per-day schedule or the hard "no-working-ahead"
cap. With one day + daily neutrality there is no incentive to overshoot, so it hits
the lumpsum quota naturally.

CLOSED-LOOP CORRECTNESS (modular code 4_MCSModel.jl / 5_MPCLoop.jl):
 - Rolling rules (rest 12e, precedence 12d, pacing 13) are seeded from a SHARED
   per-CEV applied-activity history, so a within-window limit can no longer "leak"
   work-runs across the every-15-min re-solves (the 8-in-a-row artefact).
 - The keep-up reserve (E7) makes the hard CEV terminal (8b) recursively feasible.
 VERIFIED: synthetic + input runs finish with ZERO infeasible/held windows and every
 constraint satisfied on every row of the realised trajectory.
